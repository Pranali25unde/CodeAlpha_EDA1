# CodeAlpha EDA Project

## Exploratory Data Analysis

This project was completed as part of the CodeAlpha Data Analytics Internship.

## Objective

The objective of this project is to perform Exploratory Data Analysis on a sales dataset and identify important sales patterns, trends, and insights.

## Tools and Technologies

- Python
- Pandas
- Matplotlib
- Google Colab

## Analysis Performed

- Dataset exploration
- Data structure analysis
- Missing value checking
- Duplicate value checking
- Statistical analysis
- Product-wise sales analysis
- Category-wise sales analysis
- Quantity analysis
- Data visualization
- Business insights

## Key Findings

- Highest Sales Product: Laptop — ₹2,00,000
- Highest Sales Category: Electronics — ₹2,60,000
- Most Sold Product by Quantity: Mouse — 14 units
- Total Sales: ₹2,84,700
- Average Sales per Order: ₹28,470

## Conclusion

The Exploratory Data Analysis helped identify important sales patterns in the dataset. Laptop generated the highest product-wise sales, while Electronics was the highest-performing category. Mouse had the highest quantity sold. The analysis also confirmed that the dataset contained no missing or duplicate values.
